# English edition: how translation works

The English edition does not edit upstream source strings. `src/i18n/` translates Chinese text
at display time, so upstream changes merge without conflicts in feature code.

## Runtime

- `src/ui/gui_startup.py` calls `src.i18n.install(language, root)` before the main window is built.
  The language comes from `"language"` in `config/global_ui_preferences.json` (default `en`;
  `zh` shows the original Chinese). Settings → Tool Settings → Language switches it, then restarts.
- `src/i18n/qt_patch.py` patches PySide6 text setters (labels, buttons, tooltips, combo boxes,
  tabs, tables, message boxes, form rows, painter text). Getters such as `text()`,
  `currentText()` and `tabText()` return the original Chinese while the translation is shown,
  so code like `button.text() == "保存"` keeps working.
- `src/i18n/catalog.py` looks text up in this order: exact match, trimmed match, line by line,
  `{field}` templates (captured values are translated recursively), then piece by piece
  (`"1. " + name`, `label + "："`). The piece-by-piece step only succeeds if no Chinese is
  left, so users never see half-translated text. Untranslated text stays Chinese.
- Only display changes. Logs, saved data, OCR matching and the database keep Chinese.

## Catalog files (`locales/en/`)

| File | Contents | Produced by |
|---|---|---|
| `game.json` | Official zh→en game text (characters, Arcs, Modules, sets, stats, skills, monsters, items) | Generated from the game's official English localization; edit `game_extra.json` or `manual.json` instead |
| `game_extra.json` | Game text with no official English yet (CN-only content); unofficial translations | hand/worker translated |
| `ui_*.json` | Strings from `src/`, split by area | `tools/i18n/extract_strings.py`, then translated |
| `manual.json` | Small hand-written additions | by hand |

Empty values mean "not translated". About 30 `ui_*` keys stay empty on purpose: they are OCR match
tokens, regular expressions or SQL that must keep their Chinese text.

## After merging an upstream update

```bash
python tools/i18n/extract_strings.py          # adds new strings (empty), keeps existing translations
python tools/i18n/check_catalog.py            # shows what is untranslated / invalid
python tools/i18n/translate_helper.py todo locales/en/<file>.json   # next untranslated entries
python tools/i18n/translate_helper.py apply locales/en/<file>.json patch.json
python tools/i18n/audit_ui.py                 # screenshots every page; lists Chinese still on screen
```

`audit_ui.py` writes `build/i18n/audit/untranslated.json` and one PNG per page. It runs on
Windows, or headless on Linux with Windows-only modules stubbed.

## Known gaps

- The first-run tutorial images (the `guide/` folder under the template directory, shown by
  `src/features/onboarding/guide.py`) are screenshots with Chinese text drawn in.
- Text drawn from Python-side item models' `data()` is not patched. Nearly everything goes
  through widgets; check `audit_ui.py` output when something is missed.
- The OCR scanner reads the game screen and expects the game client in Simplified Chinese.
